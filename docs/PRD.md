# 祜·Care 产品需求基线（PRD）

- 状态：V0.1 / 讨论基线
- 项目：祜·Care（Hu-Care）
- 阶段：产品与工程准备；本阶段不实现业务代码

## 1. 产品定位

祜·Care 是面向个人私募股权（PE）投资经理的 AI-native 工作空间。它不只是聊天窗口，而是围绕项目、证据、分析过程、判断和复盘组织工作。

核心目标：帮助投资经理更系统地完成单个项目的深度尽调、财务分析、风险验证与投资判断，同时逐步积累可检索、可复用的个人投资认知。

## 2. 产品原则

1. **证据优先**：重要结论应关联来源、数据、时间和推理过程；无法验证的内容明确标注。
2. **人负责最终判断**：AI 提供研究、反证和建议，不自动替代投资决策。
3. **项目为中心**：材料、任务、分析、结论与复盘均归属明确项目或研究主题。
4. **过程可追溯**：记录任务状态、模型/技能执行结果、关键输入输出和人工确认。
5. **模块化扩展**：技能、数据连接器和工作流通过清晰接口接入，避免绑定单一供应商。
6. **先做深、再做广**：MVP 优先解决单项目深度尽调和风险验证，不追求一开始覆盖所有投资场景。

## 3. 目标用户与核心场景

### 目标用户
- 首要用户：个人 PE 投资经理。
- 主要使用方式：单人工作台；后续再考虑团队协作、权限和审计扩展。

### MVP 核心场景
- 创建项目并维护项目资料。
- 导入或登记项目材料与外部来源。
- 调用尽调、财务分析、PE 研究技能完成分析任务。
- 将重要事实、判断、风险和反证整理为有来源的证据记录。
- 生成可审阅的研究结果与报告草稿。
- 记录投资判断、后续验证事项及复盘内容。

## 4. 产品结构

### 一个入口
**AI 投资 Copilot**：自然语言任务入口，理解用户意图并把工作组织为可追踪任务，而不是只返回一次性回答。

### 两个引擎
1. **投资研究引擎**：项目尽调、财务分析、风险识别、证据汇总、报告生成。
2. **投资认知引擎**：投资判断记录、假设跟踪、决策复盘、个人方法与记忆检索。

### 共享基础能力
- 项目库与文件/材料索引
- 来源与证据管理
- 任务和工作流状态
- Skills / 技能适配层
- 数据连接器
- 个人记忆与检索
- 人工确认、权限与审计记录

## 5. MVP 范围

### 必须包含
- 项目列表、项目详情和项目基础信息。
- 项目材料/来源登记及证据条目。
- 任务创建、状态、结果与错误信息。
- 技能调用的统一适配接口；技能执行能力需先做现状审计。
- 研究结论、风险、待验证事项和来源之间的关联。
- 报告草稿查看与导出/复制的基本路径。
- 判断记录与复盘的最小数据结构。
- 清晰的加载、空状态、失败状态和人工确认体验。

### 暂不纳入
- 自动作出或执行投资决策。
- 未经核实就声称可访问第三方付费数据源。
- 复杂多租户、团队组织和企业级审批体系。
- 全自动交易、资金调度或对外发送未经审核的报告。
- 为了架构完整而提前建设大量未被 MVP 使用的微服务。

## 6. 技能与数据源

现有候选技能名称（需盘点后确认实际可运行性与接口）：
- `hu-inv-dd`
- `hu-inv-fin-analysis`
- `hu-inv-PE`

候选数据源/服务（需核验账号、授权、API、费用及使用条款）：
- 观研/行业研究相关来源（用户提及的 Gangtise）
- 执中
- 天眼查

不得将“已提及”视为“已接通”。所有外部连接器必须有明确的凭证管理、错误处理和来源记录。

## 7. MVP 验收标准

- 用户能创建项目并看到项目详情。
- 用户能为项目登记材料/来源，并查看证据与来源的对应关系。
- 用户能发起研究任务并查看任务状态、输出和失败原因。
- 研究输出能区分事实、推断、假设、风险和待验证问题。
- 关键结论可回溯到来源；缺少来源时必须明确提示。
- 用户可以人工修改、确认或否决 AI 输出。
- 判断和复盘可关联项目、时间、论据与后续结果。
- 核心流程具备基本自动化测试与错误状态说明。
